# Security Policy

## Reporting a Security Vulnerability

If you discover a security vulnerability affecting Avora, please report it privately to the repository owner.

Please do not disclose security vulnerabilities publicly until they have been reviewed and addressed.

Include the following information in your report:
- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential security impact.
- Any relevant screenshots or technical details.

Please do not include passwords, private keys, access tokens, or other sensitive personal information in your report.

## Response

Reports will be reviewed as time and resources permit. Please avoid publicly disclosing unpatched vulnerabilities.

## Scope

This policy applies to security vulnerabilities affecting Avora and its associated repository.
